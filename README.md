# モンキーターンⅤ 超抜チャレンジシミュレーター

スマートフォンでも遊べる、10Gの超抜チャレンジ抽選シミュレーターです。

## 公開方法
GitHub Actions が main ブランチへの push を検知し、GitHub Pages に自動デプロイします。
リポジトリの Settings → Pages で Build and deployment の Source が GitHub Actions になっていることを確認してください。

## 抽選仕様
- 1回10G、1Gずつ進行
- ペラ出現率は各チャレンジ開始時に50〜75%から整数でランダム決定し、結果まで非表示
- レア役出現率は一撃掲載の通常時／AT中の小役確率を使用
- AT当選期待度：ペラ9.4%、ボート・弱チェリー33.6%、強チェリー100%、弱チャンス目50%、強チャンス目100%
- ペラ・レア役の成立合計9回で強制クリア
- チャレンジ履歴は結果欄1か所に集約
